## Repository description

Editable launch films and product ads. Local HTML-to-video rendering, keyless demo, optional image/video/audio generation with Raywake.

## English

We opened up the tools behind our motion work.

motion-engine turns editable HTML and JavaScript into a finished launch film: MP4, poster, contact sheet and source. The bundled Raywake demo runs locally without an API key or a generation charge.

Bring your own media, or use Raywake to generate images, video and audio. Get a USD quote before you start, set a spending cap, and resume interrupted jobs with the same identity.

Three formats. Editable timing. MIT code.

https://github.com/oguzhankayan/motion-engine
