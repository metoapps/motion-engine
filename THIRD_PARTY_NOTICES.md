- **motion-kit**: this project extracts the author's local motion runtime and production approach into an independent, portable package. The original working folder is not part of this repository.
- **saas-motion-kit contributors**: the production playbook approach and warm sound synthesis originate in [saas-motion-kit](https://github.com/tugrawork-creator/saas-motion-kit), MIT. The adapted sound synthesizer and synthesized sound files preserve that attribution. The original MIT notice is in [licenses/saas-motion-kit.txt](licenses/saas-motion-kit.txt). File hashes are recorded in docs/showcase/SOURCES.json; this work is not claimed as original theme design.
